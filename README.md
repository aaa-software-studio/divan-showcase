## فارسی

### دیوان؛ خانهٔ شعر فارسی

گاهی می‌خواهیم سراغ شاعر محبوبمان برویم، بیتی را پیدا کنیم یا چند دقیقه شعر بخوانیم. دیوان برای همین لحظه‌ها ساخته شده است: یک اپ اندرویدی با کتابخانهٔ آفلاین شعر فارسی، جست‌وجو و فضایی برای نگه‌داشتن شعرهای دلخواه.

در دیوان می‌توانید میان شاعران و آثارشان بگردید، شعر بخوانید و ظاهر صفحهٔ مطالعه را مطابق سلیقه‌تان تنظیم کنید. رابط فارسی و راست‌به‌چپ، کارت‌های روشن و جزئیات طلایی، ظاهر اپ را شکل می‌دهند.

### در دیوان چه می‌توانید پیدا کنید؟

- **شاعران و آثارشان:** مرور کتابخانه و رفتن از نام شاعر به آثار او.
- **جست‌وجوی شعر:** پیدا کردن محتوای موردنظر در کتابخانهٔ فارسی.
- **علاقه‌مندی‌ها:** نگه‌داشتن موارد دلخواه برای مراجعهٔ بعدی.
- **شعر روز و فال حافظ:** دسترسی به انتخاب روزانهٔ شعر و بخش فال.
- **تنظیمات مطالعه:** شخصی‌سازی ظاهر و ترجیحات خواندن.
- **اشتراک شعر:** کپی متن و استفاده از امکان اشتراک‌گذاری متن یا تصویر شعر.
- **معنی و تفسیر:** توضیحات همراه بخشی از آثار؛ این محتوا هنوز در حال بازبینی ادبی است.

سازنده، آزمون نسخهٔ پیشین را روی گوشی و تبلت موفق گزارش کرده است. نسخهٔ ۰٫۳٫۱ شامل بازبینی مجموعهٔ محتوایی و به‌روزرسانی کتابخانه است؛ این گزارش به معنی آزمون مستقل همهٔ دستگاه‌ها نیست. برای تفسیرها نیز پوشش یا صحت کامل ادعا نمی‌کنیم.

## English

### About the App

Divan is an Android Persian poetry reader with an offline library and a right-to-left interface. Implemented areas include poet/work browsing, Persian search, local favorites, reading preferences, daily selections, Hafez fortunes and text/image sharing workflows. Interpretations are an editorial work in progress.

Built with **Kotlin, Jetpack Compose, Room/SQLite and DataStore**. The reviewed source manifest does not request Internet permission. Android sharing passes selected content to the chosen destination app, whose own policies apply.

### Current Release

The current public release is **0.3.1, build 12**, for Android 8.0+. A Release APK has been signed locally; the developer's report records signature validation and 16 KiB alignment checks.
