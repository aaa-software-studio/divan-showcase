## فارسی

### دیوان چیست؟

دیوان یک اپ اندرویدی برای خواندن و جست‌وجوی شعر فارسی است. کتابخانهٔ محلی، مرور شاعران و آثار، علاقه‌مندی‌ها و تنظیمات خواندن را در یک رابط راست‌به‌چپ کنار هم قرار می‌دهد. طراحی آن از رنگ‌های روشن، جزئیات طلایی و کارت‌های نرم استفاده می‌کند.

این اپ برای کسی ساخته شده که می‌خواهد شعر را روی گوشی بخواند، میان آثار جست‌وجو کند و شعرهای دلخواهش را برای مراجعهٔ بعدی نگه دارد. کتابخانهٔ اپ برای استفادهٔ آفلاین طراحی شده است؛ نسخهٔ Release جدید هنوز به آزمون عملی دستگاه نیاز دارد.

### امکانات پیاده‌سازی‌شده

- **مرور شاعران و آثار:** دسترسی به فهرست شاعران و محتوای کتابخانه.
- **جست‌وجوی فارسی:** جست‌وجو در کتابخانه با نرمال‌سازی حروف فارسی.
- **علاقه‌مندی‌ها:** ذخیرهٔ محلی موارد دلخواه.
- **تنظیمات خواندن:** تغییر ظاهر و ترجیحات مطالعه.
- **شعر روز و فال حافظ:** مسیرهای اختصاصی برای انتخاب و خواندن شعر.
- **اشتراک‌گذاری:** جریان‌های کپی و اشتراک متن یا تصویر شعر از طریق برنامه‌های مقصد اندروید.
- **معنی و تفسیر:** محتوای توضیحی موجود است، اما بازبینی ادبی آن کامل نشده و دقت یا پوشش کامل ادعا نمی‌شود.

میزان بررسی هر بخش یکسان نیست. وجود قابلیت در کد یا تصویر، به‌تنهایی به معنی موفقیت آزمون عملی آن نیست.

### نسخهٔ فعلی و دانلود

نامزد فعلی **0.3.0-preview.1، شمارهٔ ساخت 9** است و برای **Android 8.0 به بالا** ساخته شده است. فایل Release با کلید غیر Debug امضا شده؛ بررسی اعتبار امضا و هم‌ترازی ۱۶ KiB در گزارش توسعه ثبت شده است.

در بررسی مستقل بسته‌ها، هش فایل‌ها، سلامت ساختار آرشیو، تغییرنکردن محتوای APK پس از امضا و تطابق داده‌های همراه اپ با سورس ارائه‌شده کنترل شد. این بررسی‌ها جای آزمون دستگاه یا ارزیابی امنیت کامل را نمی‌گیرند.

سازنده استفادهٔ موفق از نسخهٔ Debug قبلی را گزارش کرده و تصاویر واقعی گوشی را ارائه داده است. نصب تازه، اجرای آفلاین، ماندگاری علاقه‌مندی‌ها و اشتراک‌گذاری روی همین Release جدید هنوز باید بررسی شوند. وضعیت مجوز بازتوزیع محتوای ادبی و تصاویر و شرایط استفادهٔ اپ نیز در حال تکمیل است.

**فعلاً لینک دانلود عمومی APK ارائه نمی‌شود.** سورس و بسته‌های بازبینی خصوصی هم در این مخزن قرار ندارند.

### داده‌ها و حریم خصوصی

در مانیفست سورس بررسی‌شده مجوز اینترنت وجود ندارد و ذخیرهٔ کتابخانه و تنظیمات بر پایهٔ داده‌های محلی طراحی شده است. هنگام اشتراک‌گذاری، محتوای انتخاب‌شده به برنامهٔ مقصد اندروید سپرده می‌شود و رفتار آن برنامه تابع سیاست‌های خودش است.

اطلاعات شخصی، کلیدهای امضا، اعتبارنامه‌ها و فایل‌های اجرایی خصوصی جزو محتوای این مخزن نیستند. این توضیح به معنی تضمین نبود همهٔ آسیب‌پذیری‌ها نیست.

## English

### About the App

Divan is an Android Persian poetry reader with an offline library and a right-to-left interface. Implemented areas include poet/work browsing, Persian search, local favorites, reading preferences, daily selections, Hafez fortunes and text/image sharing workflows. Interpretations are an editorial work in progress.

Built with **Kotlin, Jetpack Compose, Room/SQLite and DataStore**. The reviewed source manifest does not request Internet permission. Android sharing passes selected content to the chosen destination app, whose own policies apply.

### Release Preparation

The current private candidate is **0.3.0-preview.1, build 9**, for Android 8.0+. A Release APK has been signed locally; the developer's report records signature validation and 16 KiB alignment checks.

Independent package checks confirmed hashes, archive integrity, unchanged APK content after signing and matching bundled assets between the candidate and supplied source. They are not a full security audit or proof of source-to-binary reproducibility.

The creator reports successful use of an earlier Debug build. The new Release candidate still requires device acceptance checks, literary review, content/image rights documentation and application licensing decisions. **A public APK download is not available yet.**

### Telegram

[Use Divan on Telegram](https://t.me/DivanYar_bot)

The bot is presented separately from the Android app. Earlier demonstrations include poet browsing, search, Hafez fortunes, favorites and text sharing. The supplied developer report records a public-profile check on 2026-10-23; current command responses were not independently tested during this review. Identical features or a shared backend are not assumed.
